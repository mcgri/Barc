## Changes

- Fixed GoDaddy's Microsoft 365 sign-in, which answered "Your browser is a bit unusual..." in Barc. GoDaddy's bot check rejects the values anti-fingerprinting masks, and turning the protection off for the site did nothing: the script carrying each site's settings ran after the page scripts that read it, so anti-fingerprinting and hostile-page blocking stayed on everywhere. The site settings now load first, so per-site and global switches for both take effect on the next page load.
- New floating **Anti-Fingerprinting** switch in the bottom-right corner of sites known to refuse the protection, starting with sso.godaddy.com. It changes the site's own setting, the same one in Site Settings, and reloads the page. Close it to hide it for that site until Barc quits.

## Verification

The full suite ran 2,517 tests in 403 suites. Two saved-login suggestion tests failed under full-suite load; they fail identically on 0.0.6 and pass in isolation. In a WebKit test harness, GoDaddy's sign-in was refused with Barc's page scripts as 0.0.6 loaded them and accepted once anti-fingerprinting was off.
