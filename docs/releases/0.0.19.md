## Changes

- **Tighter JavaScriptCore memory tuning for giant SPAs**: lowered `forceRAMSize` from 2 GiB → **1 GiB** in minimal-RAM mode (moving JSC's critical GC threshold from ~1 GB down to ~512 MB), tightened `concurrentGCMaxHeadroom` to `1.15`, raised `thresholdForOptimizeAfterWarmUp` to `2500`, and lowered `maximumOptimizationCandidateBytecodeCost` to `20000` so JSC avoids DFG-compiling thousands of one-shot Angular/React boot functions. Measured on a live ClickUp session: whole-browser RAM dropped from **2.05 GB → 1.42 GB (−31%)**, with `JS JIT Generated Code` held to just **24 MB**.
- **Eliminated per-navigation script IPC thrashing & SPA `MutationObserver` storms**:
  - Fixed `SitePolicy.apply` to serialize policy JSON with `.sortedKeys` so unchanged site policies actually short-circuit instead of calling `removeAllUserScripts()` and re-uploading ~70 KB of scripts on almost every navigation.
  - Replaced both `mediaWatcher` and `nativeVideoPlayer` `MutationObserver`s with zero-overhead capture-phase media event listeners (`play`, `playing`, `pause`, `ended`, `emptied`, `volumechange`, `ratechange`, `loadedmetadata`), eliminating per-mutation DOM scanning on React/Angular apps.
- **UI process & background tab cuts**:
  - Switched `ExtensionPanelViewController.underlay` to `.withinWindow` and disabled `cardShadow` offscreen Gaussian blur in minimal-RAM mode (`ContentContainerView` and `ExtensionPanelViewController`).
  - Rasterized `SpaceIconStore` images to compact `56×56` (`28pt @2x`) bitmaps to stop large PNGs and CoreSVG vector trees from sitting in UI RAM.
  - Migrated `WebPanelViewController` sleeping states out-of-line into `InteractionStateStore` (`lz4_flex`) so sleeping web panels keep 0 bytes of WebKit state in Swift RAM.
  - Gated eager `developerExtrasEnabled`/`isInspectable` on `showDevelopMenu` (still enabled lazily on Inspect Element / Web Inspector) and reduced `SidebarViewController` idle badge ticks from 1 s → 15 s when live idle durations are not displayed.
  - Tightened minimal-RAM background suspension thresholds: background memory budget capped at **768 MB**, heavy tabs (**≥300 MB**) sleep after **90 s**, and very heavy tabs (**≥600 MB**) sleep after **30 s**.

- Verified live `JSC.config` options and whole-browser memory via `footprint -p` (`52.0 MB` fresh launch on Start Page; `1.42 GB` vs `2.05 GB` on a live multi-space ClickUp session, dropping to `~220 MB` when unfocused).
