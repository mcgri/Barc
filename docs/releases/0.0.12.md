## Changes

- Saving images works. Right-click → **Download Image** (and **Download Linked File**) did nothing: WebKit started the download and handed it to Barc through a hook Barc never answered, so it was dropped. A site's download button whose link holds the image itself, common for generated images and charts, also did nothing. Both now save to your downloads folder, the button under the site's file name. Download buttons that build the file in the page first already worked and are unchanged.
- New **clean-up button** at the end of the **New Tab** row in the sidebar. It archives every tab in the current space that hasn't been on screen for 7 days. Pinned tabs, favourites, tabs set to Keep in Sidebar or Keep Awake, live folders, the tab on screen and any tab still holding a page (an unsent draft, a call) stay, and a split view goes only if every tab in it is old. The tabs go to the space's archive with their history, and the toast offers **Undo**.

## Verification

The full suite ran 2,558 tests in 409 suites with no failures. The new download tests open the real context menu and click real download links, and fail on 0.0.11. A session-save test that sometimes failed under full-suite load now waits for the save instead of a fixed time.

Passkeys remain unavailable in this private build.
