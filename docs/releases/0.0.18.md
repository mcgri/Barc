## Changes

- **Zero-WebKit Start Page & UI peak cuts**: native `barc://start` tabs no longer spawn a live `WKWebView` or WebKit XPC process tree until navigation (fresh launch dropped from **126.5 MB → 52.0 MB**, **−62.5%** vs System WebKit's 138.5 MB, with 0 XPC processes). Replaced stacked `.behindWindow` backdrop blur on the opaque web-card underlay with `.withinWindow` in minimal-RAM mode and gated `WebContainerView.reveal` opacity animations on `Reduce Animations`.
- **Fixed 5-minute background active-tab sleep**: `BrowserSession.suspend` now honours `allowVisible: true` when Barc has been unfocused in the background past the active-tab sleep threshold, instead of silently skipping the front tab and retrying every 10 seconds.
- **Custom WebKit GPU & WebContent RAM cuts** (heavy real-world load on The Verge + 3 tabs down to **344 MB total**, **−55.3%** vs System WebKit's 770 MB; `WebContent` down to **203 MB**, **−67.4%**, peak **912 → 247 MB**):
  - Capped per-process `IOSurfacePool` to 16 MB / 4 MB non-volatile in-use with idle surface eviction, enabled periodic `GPUProcess` memory pressure collection (`CABackingStoreCollectBlocking` + `IOSurfacePool` discard), forced 8-bit `RGBA8` layer backing stores, capped max tile dimension to 1024 pt, dropped idle triple-buffered `m_secondaryBackBuffer`, sped off-window tile pruning (`1 s`) and cohort expiry (`250 ms`), enabled ANGLE Metal `purgeableBufferPool`, capped Metal staging buffers to 8, and capped accelerated 2D canvases to 64.
  - Disabled JSC `GrowthMode::Aggressive` (4× heap growth on ≥16 GB Macs), tightened heap growth factors and disabled `MarkedBlock` warm-up, lowered `MemoryPressureHandler` conservative/strict thresholds to 205 MB / 358 MB (kill thresholds unchanged), sped hidden-tab cleanup to `3 s / 20 s` with `markLayersVolatile()` and BFCache eviction, capped BFCache to 1, cut dead decoded-image retention (`60 s → 5 s`), lowered animated GIF/WebP cutoff (`30 MB → 4 MB`), and tightened `FontCache` (`225 → 64`).
  - Added `useOMGJIT=false` and `numberOfDFGCompilerThreads=1` to `JSC.config` in minimal-RAM mode, and wired `WebViewRetirement` to the shared unwarmed process pool.
- **Closed `NetworkProcess` Rust adblock bypasses**: hooked HTTP `3xx` redirects (`willSendRedirectedRequestInternal`) and Service Worker–intercepted loads (`startWithServiceWorker` / `serviceWorkerDidNotHandle`) into `adblock-rust`, added `mainDocumentURL` fallbacks and `"ping"` resource classification, disabled `SpeculativeLoadManager`, capped `mainResourceBlobMemoryCacheFileLimit` to 4, and removed hardcoded local dev paths from the sandbox and loader.
- **Startup, state, script & timer hygiene**:
  - Filter list freshness checks now inspect file `mtime` without reading ~5.6 MB `.txt` files into memory on launch.
  - Throttled live `WKWebView.interactionState` IPC snapshots to 30 s, fixed `.barcstate` deletion on closed/archived tabs, and added orphan `.barcstate` pruning on quit.
  - Cached `DeclarativeNetRequest` navigation rules in memory instead of re-reading ruleset JSON from disk on every navigation.
  - Preferred `<html lang>` before loading `NLLanguageRecognizer` CoreNLP models, deduplicated per-URL language checks, skipped eager background Tab Overview GPU snapshots in minimal-RAM mode, debounced `CookieConsentAutoReject`'s `MutationObserver`, disconnected `hostileBehaviourBlocker`'s observer on `pagehide`, removed `selectionchange` IPC spam, capped SQLite `cache_size = -512` / `mmap_size = 0`, and gated idle lock/sync timers on feature flags.
