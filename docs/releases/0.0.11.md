## Changes

- Upload areas work. Clicking "Choose file", an attach button or a drop zone used to do nothing, because Barc never answered the page's request for a file picker. It now opens the macOS file picker as a sheet on the window. It allows several files or a folder when the site does, and shows only the file types the site accepts, as Safari does. Dragging files onto a page was already handled by WebKit and is unchanged.
- Page dialogs appear. `alert()` messages never showed and every `confirm()` silently answered Cancel, so a site's "Delete this?" or "Discard changes?" quietly did nothing. Alerts, confirmations and prompts now appear as sheets naming the site that asked, or the embedded page's site for a frame. From a page's second dialog you can stop it showing more until it navigates.
- A page in a background tab still gets the default answer instead of a dialog over another tab.

## Verification

The full suite ran 2,550 tests in 407 suites with no failures. The new upload and dialog tests fail on 0.0.10. Two tests added in 0.0.10 had timing windows too tight for full-suite load; they now have more room.

Passkeys remain unavailable in this private build.
