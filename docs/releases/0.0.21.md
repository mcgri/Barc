## Changes

- **Fixed OAuth and script-opened popups getting stuck open after `window.close()`**:
  - Implemented `WKUIDelegate.webViewDidClose(_:)` on `TabNavigationHandler` and forwarded it through `TabDelegate.tabDidRequestClose(_:)` to `BrowserSession.closeTab(_:)`, fixing OAuth callback popups (such as Google sign-in on SoundOn) that post credentials to their opener and call `window.close()` leaving a blank white screen.
  - Recorded `openerTabID` on tabs adopted via `BrowserSession.adoptChildTab(of:configuration:)` so closing an active popup tab returns focus directly to its opener tab instead of an unrelated neighbour at the top of Today.
  - Implemented `WKUIDelegate.webViewDidClose(_:)` in `PageWebCoordinator` and wired `onClose` across Glance, Little Arc, and standalone Web App windows.
- **Hardened hibernation protection for web code editors and SPA file imports (`PageHibernationGuard`)**:
  - Tracked native `NSOpenPanel` file imports by host + main-frame document token rather than exact URL so SPA `history.pushState`/`replaceState` query or route changes keep the tab awake until a real document load or cross-host navigation.
  - Detected hidden code-editor proxy `<textarea>` inputs (Monaco, CodeMirror, Ace, Google Flow), window-level `drop` events, and multi-line or large pastes so clearing the proxy input never lets Barc sleep unsaved editor state.

## Verification

- Passed **292 tests across 54 suites** (`WindowCloseTests`, `BrowserSessionTests`, `RustCoreAndStateStoreTests`, `Glance*`, `LittleArc*`, `WebApp*`, `TabSuspensionTests`, `PageHelperEfficiencyTests`, and `UITests`), including a live `WKWebView` end-to-end OAuth popup `window.open` → `BroadcastChannel` → `window.close()` test.

Passkeys remain unavailable in this private build.
