## Changes

- New tabs open at the top of the Today list, including tabs opened by websites and adopted from preview windows.
- Address-bar tab and folder suggestions stay in the current workspace. History and bookmarks use its profile. Opening a suggested URL no longer switches profiles through routing rules.
- Search waits 200 ms after the latest keystroke before running.
- Saved-login suggestions support email-first and password sign-in steps with an account chooser. Vault errors now show a retry message.
- Added a guided one-time CSV import from Apple Passwords into the selected profile. Existing passwords are preserved, and the import is saved as one encrypted batch.
- Browser identification follows the installed Safari version, fixing Gmail's unsupported-browser detection for the default configuration and Safari mode.

## Password and passkey limits

Apple Passwords import copies website passwords only. It does not import passkeys or verification codes, and does not enable iCloud synchronization. Apple browser approval is still required for iCloud passkeys and the iCloud Passwords extension. Delete unencrypted CSV exports after importing.
