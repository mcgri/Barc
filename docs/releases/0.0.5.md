## Changes

- Saved-login suggestions leave keyboard focus in the field. Typing dismisses suggestions, empty results show no popup, and delayed lookups cannot overwrite text entered while waiting. Click and arrow-key account selection still work.
- Idle pages can sleep after background requests finish. Untouched read-only controls no longer look like unsaved drafts. Unsent edits, active calls, uploads and other protected work still keep pages awake.
- Split views recheck every pane immediately before sleeping. A draft started during the safety check keeps the entire split open.
- Closed previews, floating pages, small browser windows and standalone web apps release their old documents even when another component retains the view. Pages handed over to a new tab or panel stay live.
- Performance identifies auxiliary web content by surface, domain and visibility. Shared processes are counted once; process memory still includes WebKit and caches.
- Restored scroll positions stay stable after WebKit finishes loading. Fresh user input cancels any pending scroll adjustment.
- Fixed page-height oscillation with docked developer tools, including normal tabs and split views.
- Updated the README and project description around Barc's purpose as a personal browser with the original Arc feel and a smaller footprint.

## Verification

Native regression and integration checks cover typing with suggestions visible, explicit account selection, delayed replies, draft and transfer protection, closed-page cleanup, cookies, history, scroll restoration and the one-minute hibernation scheduler. Live checks confirmed automatic idle sleep and typing in the installed browser, with saved tabs preserved.

Detailed verification records: [idle-page memory](https://github.com/mcgri/Barc/blob/v0.0.5/docs/idle-page-retention-2026-10-27.md), [page sizing](https://github.com/mcgri/Barc/blob/v0.0.5/docs/page-layout-verification-2026-10-26.md), and [login suggestions](https://github.com/mcgri/Barc/blob/v0.0.5/docs/login-suggestion-input-2026-10-27.md).

WebKit controls process reuse and cache reclamation. These changes fix reproduced problems; they do not impose a fixed memory limit on websites. Passkeys remain unavailable in this private build.
