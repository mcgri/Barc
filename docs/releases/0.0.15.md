## Changes

- Moving to a new site in a tab no longer stops dead. On a tab's second move to a new site, the page stayed where it was and nothing happened, with no error. Signing in to FreeAgent with Google showed it: searching for FreeAgent, opening its login page and pressing Sign in with Google did nothing.
- The cause was Barc's own page memory setting. After a tab's first move between sites, WebKit keeps a spare process ready, and that process crashed reading Barc's memory options. WebKit tells the browser nothing when that happens, so Barc had no error to show.
- Keep page memory compact still applies. Tabs now run without the spare process.

## Verification

The full suite ran 2,580 tests in 410 suites with one failure: a sidebar layout test that fails the same way on the 0.0.14 code. The new test for the second move fails with the fix removed, and the memory tuning tests also pass in an optimised build. The FreeAgent failure was reproduced on demand before the fix. After it, a real Google sign-in reached a FreeAgent account in the installed app, with no crash and no spare process in WebKit's log.

Passkeys remain unavailable in this private build.
