## Changes

- **Disk-offloaded tab rehydration (`TabRehydrationStore`) & larger `interactionState` cap**:
  - Raised `InteractionStateStore.maxUncompressedBytes` from **256 KB → 8 MB** (LZ4-compressed to ~50–400 KB on disk, **0 bytes in Swift RAM**), preventing silent back-forward/scroll/form loss on heavy SPA tabs (ClickUp, GitHub, Gmail, Linear).
  - Added LZ4-compressed out-of-line `.pagestate` snapshots (`TabStates/<id>.pagestate`) capturing `window.sessionStorage`, window + up to 16 nested scrollable containers (scanned with a 3,000-node container cap), and non-sensitive form/textarea/select/checkbox/`contenteditable` drafts (strictly excluding passwords, hidden fields, files, and credit-card/OTP fields, and never written for private spaces).
  - On wake or `webViewWebContentProcessDidTerminate`, `sessionStorage` is injected via a one-shot `.atDocumentStart` script scoped strictly to the exact origin before SPA scripts boot, nested scrolls and form drafts restore progressively (cancelled immediately on any user input), and `.pagestate` is consumed and deleted from disk once rehydrated or on new navigation.
- **Prevented data loss on web editors with imported local files (`flow.google.com`, Figma, JSON tools)**:
  - Native `NSOpenPanel` file picks (`FileUploadPanel`) and in-page file `drop`, `<input type="file">` `change`, and non-search `paste` events now protect the current document from automatic hibernation even after the web app reads the file into JS memory and clears or unmounts `<input type="file">`.
- **Fixed ChatGPT CSS Grid crash & reload loop**:
  - Disabled WebKit nightly's crashing `GridFormattingContextIntegrationEnabled` (GFC) layout integration at runtime via `WKPreferences` so WebKit falls back cleanly to mature `RenderGrid`, eliminating `LayoutIntegration::GridLayout::~GridLayout()` `WebContent` crashes.
  - Added a crash-loop breaker in `Tab.contentProcessDidTerminate` (max 2 automatic recoveries per 30 s before showing a retryable error page instead of reloading forever).
- **Wired per-site Shield toggle & Settings filter-list toggles into Rust `NetworkProcess` adblocking**:
  - `ContentBlocker` now writes `exempt-hosts.txt` and `active-lists.txt` into `filter-lists/`; `RustCore` (`libbarc_core.dylib`) hot-reloads `exempt-hosts.txt` by `mtime` so turning the Shield button off on a site works in Custom WebKit too, and `preferencesChanged()` skips compiling WebKit DFAs when Rust `NetworkProcess` adblocking is active.
- **Hibernation false-positive, `session.json`, and UI startup trims**:
  - Exempted hidden script-written fields (`g-recaptcha-response`, `h-captcha-response`, `cf-turnstile-response`, Gmail's `hist_state`) and empty-body `GET`/`HEAD` XHRs (`xhr.send("")`, e.g. Gmail's 60 s push channel) from blocking hibernation.
  - Migrated legacy pre-`0.0.17` inline `interactionState` blobs out of `archivedTabs` into `InteractionStateStore` (halving `session.json` on upgraded profiles from ~1.4 MB → ~730 KB).
  - Lazily instantiated and docked `ExtensionPanelViewController` and collapsed `WebPanelViewController` on first open, and skipped attaching `WKWebExtensionController` when 0 extensions are installed.
