## Changes

- Background tabs that 0.0.9 still kept awake for days now go to sleep. After two days of normal use, 0.0.9 used 5.6 GB, and about 4 GB of it was six background tabs its sleep check refused: two Gmail tabs, ChatGPT, Vercel and two GitHub pages.
- Gmail keeps a request open all day, and Barc treated any request still sending as an upload in progress. Now a request counts as an upload for as long as it takes only if it carries a file or 64 KB or more; anything else counts for its first minute. A request a page reopened before it finished no longer counts forever.
- Text left in a field the page had since removed kept the tab awake forever: the edit box of a message you already sent, a title you renamed, a dialog you closed. A removed field now protects the tab for two more minutes. Text in a field still on the page still protects it for as long as it's there.
- "Go to file", "Find a branch" and "Jump to" boxes now count as search boxes, like the search fields 0.0.9 already ignored.
- With measurement logging on, Barc names the field (by its label, never its contents) or the request that kept a tab awake.

## Verification

The full suite ran 2,542 tests in 405 suites with no failures. Each new test fails on 0.0.9.

Savings depend on the websites you keep open. Passkeys remain unavailable in this private build.
