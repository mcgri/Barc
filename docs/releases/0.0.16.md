## Changes

- Tabs no longer stay awake for hours on "Page changed since its safety check registered". When a tab moved to another site, the page it left could report in after the new page had started, and Barc kept checking the page that was gone. Website previews stayed loaded for about a day this way. Reports from a page the tab has left are now ignored.
- A tab whose page never loaded can now sleep. A restored tab pointing at a server that isn't running, like a local development server, waited for a safety check that never came, for 9 hours or more. It now sleeps if it is still an empty page with no fields or scripts. A link that fails to load from a page with a draft still keeps the draft safe.
- A page that keeps a tab awake is checked less often. Barc asked it every 10 seconds; it now waits 30 seconds, then 1, 2 and 4 minutes, then every 5 minutes, as long as the page is idle. Anything the page does, or macOS running short of memory, brings the check forward.
- A Favorite can go back to its own address. Reset Tab is on the Favorite's menu and in the command bar. Clicking the Favorite already on screen does the same when its page has moved to another site, as Gmail does when a signed-out session sends it to Google's marketing page.
- "Open Link in New Window" and the other WebKit new-window items on a page's menu are now called "Open … in New Tab", which is what they do. Hidden menu items match either name.
- The measurement log, when turned on, now starts again at 5 MB and keeps one previous file. It had reached 15 MB in eight days.

## Verification

The full suite ran 2,597 tests in 415 suites with 3 issues, all in two sidebar layout tests. One of them fails the same way on 0.0.15; the other passes when run on its own. The new tests for a page left behind on a site change and for a page that never loaded fail on 0.0.15. The sleep and Favorite tests also pass in an optimised build. The stuck tabs were found in a real session's measurement log, where Vercel previews, GitHub and local development servers had been kept awake for 9 hours to a day.

Passkeys remain unavailable in this private build.
