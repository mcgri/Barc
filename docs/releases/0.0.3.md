## Changes

- Inactive profiles begin hibernating eligible pages after one minute. Change the timeout to one, five or ten minutes, or disable it, in Settings → General. Returning to a profile reloads only its selected page or visible split.
- Hibernation preserves profile storage and login cookies. Edited forms, file selections, calls, capture, uploads, active or resumable downloads, picture-in-picture, Keep Awake pages and automatic-refresh dashboards stay protected. Pages whose safety cannot be established remain loaded.
- Hidden web panels now sleep when safe and load on demand. Drafts and scratchpads remain resident.
- Preview images have memory limits, session encoding and writes run off the main thread, and unloaded tabs stop their reload timers. Background pages receive normal visibility events, and page scripts do less repeated scanning.
- Resource readings account for shared processes consistently and label unavailable measurements. The optional performance gauge is visible beside Home at the bottom of the sidebar.
- Full-page screenshots include offscreen content and long-page footers, with bounded raster dimensions. Added a full-page clipboard action; capture feedback appears after a successful capture.
- Fresh installations offer a one-time default-browser invitation. General settings keep the current default-browser status visible and check both HTTP and HTTPS links.

## Verification

The full regression suite passed: **2,444 tests in 387 suites**. Live page tests cover drafts, cross-origin frames, calls, transfers, login cookies, scroll restoration and repeated unloading. A separate **31-minute, 26-cycle soak** completed with no retained old web views or lost fixture session cookies. These are controlled checks, not a fixed memory-saving promise for arbitrary websites.
