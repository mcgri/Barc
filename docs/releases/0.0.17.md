## Changes

- Added an optional Apple Silicon **Custom WebKit + RustCore** build (`Barc-0.0.17-arm64-custom-webkit.dmg` and `.pkg`), cutting whole-browser RAM roughly in half on heavy sites (measured at **387 MB vs 770 MB** on The Verge + 3 tabs; `WebContent` down **61.2%** from 623 MB to 242 MB, peak down **69.1%** from 912 MB to 282 MB).
- Embedded a 2 MB Rust core (`libbarc_core.dylib`) with Brave's FlatBuffers-backed `adblock-rust` engine (187,923 rules in ~11 MB once for the whole browser, ~2.9 ms warm load) and `lz4_flex` compressed state I/O. In the custom WebKit build, `adblock-rust` runs directly inside `WebKit::NetworkProcess` so `WebContent` processes no longer map compiled `WKContentRuleList` DFAs per tab.
- Included the reproducible custom WebKit patchset (`Tools/webkit-patches/barc-minimal-ram.patch`): aggressive `libpas` dirty-page scavenging (50 ms period, 16-tick TLC decommit), zero-capacity `WebProcessCache` to stop 30-minute zombie web processes, tighter GPU tile coverage (`1.15× × 1.35×` instead of `2× × 3×`), and a 16 MB / 4 MB dead `MemoryCache` cap.
- Moved `WKWebView.interactionState` out of `session.json` into out-of-line LZ4-compressed files (`InteractionStateStore`, 256 KB cap), keeping sleeping tabs at 0 bytes of WebKit state in Swift RAM and shrinking `session.json` dramatically.
- Hardened JavaScript and WebKit memory tuning: shared unwarmed `WKProcessPool`, `processCacheEnabled = false`, 2 GB JSC memory cap, and `useFTLJIT = false` by default.
- Defaulted **Hide generic page elements** to off and pruned orphaned compiled rule lists on launch.
- Defaulted to reduced animations (skipping spring animations and Space-switch PDF stills) and rasterized space symbols to 36×36 `@2x` bitmaps instead of CoreSVG layers.
- Improved tab hibernation: SPA comboboxes (`react-select`, `role="combobox"`) and toolbar filter checkboxes no longer keep idle tabs awake, idle memory-cache purges run automatically, and unfocused active tabs sleep after 5 minutes.

## Verification

- 50 tests across 8 memory, suspension, motion, and RustCore suites passed (`RustCoreAndStateStoreTests`, `JavaScriptMemoryTuningTests`, `ScriptMemoryGatingTests`, `TabSuspensionTests`, `SpringMotionTests`).
- Live side-by-side disposable-profile benchmarks (`Tools/benchmark-memory.sh`) verified whole-process-tree physical footprint (`footprint -p`) and `vmmap` linkage across UI, `WebContent`, `Networking`, and `GPU` processes.
- Verified `adblock-rust` inside `WebKit::NetworkProcess` actively blocks third-party ad/tracker requests (`googlesyndication.com`, `google-analytics.com`) while allowing first-party requests, keeping `Networking` at ~14–23 MB total.

Passkeys remain unavailable in this private build.
