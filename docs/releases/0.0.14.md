## Changes

- Printing a PDF now prints the PDF. Barc's PDF viewer is drawn over the tab's web page, and Print was printing that hidden page instead: the page you came from, or a blank white sheet when the PDF had opened in a pop-up. A PDF opened in a new tab refused with "Nothing to print yet" while it was on screen.
- Export as PDF on a PDF tab now saves that PDF, not the page underneath.
- Print buttons on websites now work. They call `window.print()`, which did nothing in Barc. They open the normal print panel, and printing a PDF embedded in a page prints the PDF rather than the page around it. A page that keeps asking straight after a print can't trap the window in print panels.
- A PDF that forbids printing now says so, and the start page says there is nothing to print instead of offering a blank sheet.

## Verification

The full suite ran 2,576 tests in 410 suites with no failures. The 14 new print tests read back what a print job actually produced, and the tests for each fix fail with that fix removed. The real print panel was opened on a PDF and showed it in the preview. Google's own Print button in Gmail and Drive was not tested, because that needs a signed-in account.

Screenshot, View Source, Reader and Translate on a PDF tab still act on the hidden page.

Passkeys remain unavailable in this private build.
