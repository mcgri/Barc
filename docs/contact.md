# Contact and reports

Barc support lives in [the Barc repository](https://github.com/mcgri/Barc/issues).

Help → Report a Problem, Suggest a Feature and Contact Support open the report sheet. The sheet prepares a GitHub issue draft containing the user's message and the displayed application version, build, macOS version and Mac model. The user reviews the draft on GitHub before publishing it. There is no direct report-submission server, automatic report upload or background retry.

Barc does not use Kylmora's contact service or support email addresses. Vulnerabilities must use a private channel as described in [SECURITY.md](../SECURITY.md).
